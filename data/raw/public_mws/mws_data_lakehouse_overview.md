# MWS Data Lakehouse Overview

The public MWS Data Lakehouse documentation describes LakeHouse as a platform for working
with big data based on separation of compute resources and storage. The audience described
by the public docs includes data engineers, data analysts, and specialists involved in
data loading and processing.

The public quick-start section points users toward obtaining namespace access, learning
the available services through KubeSphere, using JupyterHub for debugging code, and
creating an initial ETL project.
