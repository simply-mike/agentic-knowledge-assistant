# MWS Object Storage Access Control

Public documentation summary for demonstration purposes. This project is not affiliated
with MTS or MWS. This file summarizes public documentation only and does not contain
private or internal materials.

The public Object Storage access documentation describes two access-control mechanisms:
IAM roles and bucket policies. The documentation frames access management around the
principle of least privilege.

For this demo RAG project, this public page is useful because it parallels the simulated
metadata permission model used in the assistant. The project does not implement real MWS
IAM or bucket policy enforcement. It only demonstrates retrieval-time metadata filtering.

Questions about object storage access should be answered with this distinction: public
MWS documentation describes IAM roles and bucket policies, while this portfolio assistant
uses a simplified role filter for demonstration.
