# MWS Cloud Platform Overview

MWS Cloud Platform is described in the public documentation as a cloud platform made of
connected services for distributed computing. The platform gives users access to cloud
compute resources and related cloud service categories such as virtual machines, storage,
virtual networks, and other infrastructure services.

The documentation describes management through standard interfaces, including a web
console, command-line interface, and public API. It also mentions administrative services
such as Resource Manager, Identity and Access Management, and Billing.
