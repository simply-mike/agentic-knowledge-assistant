# MWS Data Kafka Ingestion

Public documentation summary for demonstration purposes. This project is not affiliated
with MTS or MWS. This file summarizes public documentation only and does not contain
private or internal materials.

The public MWS Data Kafka page describes an Apache Kafka ingestor. The page mentions
preconditions and permissions for working with Kafka topics, including that listing topics
requires Describe access on the cluster resource.

The page also describes documentation-style capabilities around schema metadata,
descriptions, lineage, and properties. In the public page, schema metadata and
descriptions are presented as supported capabilities, while lineage is not listed as
supported for that source.

For the demo assistant, this public page is useful for questions about Kafka ingestion
metadata and access prerequisites in public MWS Data documentation.
